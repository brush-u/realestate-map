# 내 집 한방 뽑기 - 국토부 실시간 연동판

## 새 기능: 지역 비교분석 (실거래가 기반)
지도를 옮겨가며 원하는 위치를 최대 3곳까지 "분석지점"으로 등록하면, 각 지점은 자기 지역 +
동서남북 인접지역(반경 2km 지점 4방향 자동 탐색)을 하나의 분석 대상으로 묶어 국토부
실거래가를 비교분석합니다. 결과로 보여주는 것:
- 지점별 이번달 평균 평당가 막대그래프
- 최근 6개월 평당가 추이 선그래프 (지점별 한 줄씩)
- 지점별 층별(저/중/고층)·평형별(소/중/대형) 평균 평당가 표

우측 하단 📊 아이콘으로 "지역 비교분석" 드로어를 엽니다. 좌표 지오코딩이 필요 없는 순수
통계 집계라 검색 기능보다 훨씬 가볍고 빠릅니다.

⚠️ **CCTV 밀도, 학군, 교통 접근성, 생활 인프라, 소음/환경, 재난안전 데이터는 아직
포함되지 않았습니다.** 각각 별도의 공공 API(교육부, 환경부, 행안부 등)를 새로 검증·연동해야
하는 대형 작업이라, 국토부 실거래가 하나 붙이는 데도 이만큼 걸린 걸 감안해 하나씩
순서대로 추가하는 게 안전합니다. 우선순위를 알려주시면 다음 걸 진행하겠습니다.

## 무엇이 바뀌었나
- 목업(mockMolitDatabase) 제거 → **국토교통부 실거래 상세자료 API** 실연동
- **거래유형(매매/전세/월세) x 주택유형(아파트/오피스텔/연립다세대) 전체 6가지 조합 지원.**
  국토부는 이 조합마다 API 엔드포인트가 전부 다릅니다 (아파트매매만 별도 상세판).
  - 매매: 아파트(RTMSDataSvcAptTradeDev) / 오피스텔(RTMSDataSvcOffiTrade) / 연립다세대(RTMSDataSvcRHTrade)
  - 전세·월세: 아파트(RTMSDataSvcAptRent) / 오피스텔(RTMSDataSvcOffiRent) / 연립다세대(RTMSDataSvcRHRent)
    - 전세/월세는 같은 API를 쓰고, 월세금액(monthlyRent) 필드가 0이면 전세로 판정합니다.
  - 건물명 필드도 유형별로 다릅니다(아파트=aptNm, 오피스텔=offiNm, 연립다세대=mhouseNm) - 서버에서
    내부적으로 전부 `aptNm`이라는 이름으로 통일해서 프론트/추정시세 로직을 그대로 재사용합니다.
  - 월세는 카드/풍선말에 "보증금 X억/월세 XX만원" 형식으로 표시되고, "목표 예산" 슬라이더는
    월세일 땐 보증금 기준으로 필터링됩니다(라벨도 "보증금"으로 자동 변경).
- 국토부 API는 좌표/반경을 지원하지 않으므로: 지도 중심점 → 카카오 좌표→법정동코드 변환
  → 국토부 API 조회 → 매물별 단지주소 카카오 키워드검색으로 좌표 변환 →
  현재 반경으로 재필터링, 순서로 동작합니다.
- 국토부 인증키(MOLIT_API_KEY)와 카카오 REST 키는 서버(.env)에만 두고 클라이언트로
  절대 내려주지 않습니다. 구글맵 키는 지도 렌더링에만 필요해 클라이언트로 내려가므로,
  Google Cloud Console에서 이 키에 HTTP 리퍼러 제한을 걸어두는 걸 권장합니다.
- '역세권/숲세권/백화점 근처' 등은 국토부 실거래 데이터엔 없는 정보라, 카카오 장소검색으로
  좌표 주변에 실제 지하철역/백화점·아울렛·쇼핑센터/공원/학교가 있는지 확인해서 판별합니다
  (역세권: 500m, 백화점·아울렛·쇼핑센터: 1km, 공원·학교: 500m 이내). 백화점 조건은 카카오의
  "대형마트" 카테고리(이마트·홈플러스 등 중소규모까지 포함)가 아니라, "백화점/아울렛/쇼핑센터"
  키워드로 직접 검색해서 대형 쇼핑시설만 정확히 판별합니다. 단지명 키워드 검색도 그대로 있습니다.
  선택한 조건에 해당하는 실제 시설도 지도에 별도 색상 마커 + 중심점 연결선으로 표시됩니다.
- 준공 연도도 실제 국토부 데이터(건축년도)로 세밀하게(1년 단위) 필터링됩니다.

⚠️ **공공데이터포털에서 활용신청이 필요한 API가 5개 늘었습니다.** 아파트매매(상세)만
활용신청 하셨다면, 마이페이지에서 아래 5개도 추가로 활용신청 해주세요 (보통 즉시~몇 시간
내 자동 승인됩니다): 국토교통부_아파트 전월세 자료, 국토교통부_오피스텔 매매 자료,
국토교통부_오피스텔 전월세 자료, 국토교통부_연립다세대 매매 실거래자료,
국토교통부_연립다세대 전월세 자료. 서비스키(인증키)는 계정당 공통이라 새로 발급받을
필요는 없고, 활용신청만 추가하면 됩니다.

## 지오코딩: 구글 → 카카오 Local API로 전환

구글 클라우드 결제(빌링) 연결이 계속 막혀서, **좌표<->주소 변환** 부분을 통째로
**카카오 로컬(Local) API**로 바꿨습니다. 카카오 Local API는 결제 등록이 필요 없고,
좌표를 넣으면 법정동코드를 직접 돌려줘서 수동 시군구코드 매핑 표도 필요 없습니다
(전국 전체, 행정구역 개편에도 카카오 쪽 데이터가 갱신되므로 더 정확합니다).

- **좌표 → 시군구코드**: 카카오 `coord2regioncode` API가 10자리 법정동코드를 바로
  줍니다. 앞 5자리가 국토부 API의 `LAWD_CD`와 동일해서 매핑 테이블 없이 바로 씁니다.
- **단지 주소 → 좌표**: 카카오 키워드 검색(`/v2/local/search/keyword.json`)을 씁니다.
  아파트 단지명은 정식 주소보다 "장소 키워드"로 찾았을 때 매칭률이 훨씬 높습니다.
- **지도 렌더링(마커 표시)은 그대로 구글 Maps JS SDK**를 씁니다 - 이 부분은 원래
  문제가 없었으니 손대지 않았습니다.
- `lawdCodes.js`(서울 25개구 + 경기 주요 도시 표)는 이제 자동 조회에는 쓰이지 않고,
  화면의 "시군구코드 직접입력" 수동 입력 시 참고용으로만 남아 있습니다.

### 카카오 REST API 키 발급 (지도용 JavaScript 키와는 다른 키입니다)

1. https://developers.kakao.com 로그인 → 내 애플리케이션 → 기존에 지도용 키를
   만드셨던 그 애플리케이션 선택 (starbucks-map에서 쓰신 앱과 같은 앱이어도 됩니다)
2. "요약 정보" 탭에 **REST API 키**가 표시되어 있습니다 (JavaScript 키 밑에 같이 있음)
3. `.env`의 `KAKAO_REST_API_KEY=` 뒤에 그 값을 붙여넣으세요
4. 별도의 "서비스 활성화" 없이 바로 사용 가능하며, 결제(카드 등록) 절차가 없습니다

## 실행 방법
```bash
npm install
npm start
# http://localhost:3000 접속
```

## 알아두어야 할 제약
1. **시군구 단위 조회**: 국토부 API 특성상 검색은 지도 중심점이 속한 시/군/구
   단위로 이루어지고, 그 안에서 다시 반경으로 걸러냅니다. 중심점을 시군구 경계
   근처에 두면 옆 동네 매물은 안 잡힐 수 있습니다.
2. **카카오 API 호출 한도**: 무료 한도 내에서도 초당 호출 수 제한이 있어, 서버에서
   배치 지오코딩 시 약간의 지연(120ms)과 동시 요청 수 제한(4개)을 걸어뒀습니다.
   매물이 아주 많으면 첫 조회가 몇 초 걸릴 수 있습니다. 같은 주소는 메모리에 캐시해
   재호출하지 않습니다(서버 재시작 시 캐시 초기화, 트래픽이 커지면 Redis 등 권장).
3. **계약년월 지연**: 국토부 실거래 신고는 계약 후 최대 30일까지 늦게 올라올 수
   있어, 화면 기본값은 "이번 달"이 아니라 "지난달"로 맞춰 두었습니다.
